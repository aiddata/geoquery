# Annual VIIRS Nighttime Lights v2.2 - Count of Cloud Free Coverage
Annual VIIRS nighttime lights product Version 2.2. Count of pixels within boundary with at least 1 cloud free observation of nighttime lights. Can be used in combination with VIIRS Nighttime Light Average product to determine if sufficient coverage exists with boundary features.

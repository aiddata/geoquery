# Population Density (GPW V4.11, UN Adjusted)
Population density (UN Adjusted values) from Gridded Population of the World v4 revision 11. GPWv4 depicts the density of human population across the globe. Source data provided in 30 arc-second (~1 km) grid cells.
No additional processing of raw data.

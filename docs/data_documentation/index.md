# Data Documentation

GeoQuery provides access to two types of data: **datasets** containing the values extracted for your area of interest, and **boundaries** defining the geographic units available for selection.

- [Datasets](datasets/index.md) — browse all available datasets including temporal coverage, source information, and citation details
- [Boundaries](boundaries/index.md) — browse all available boundary sets, including administrative level, feature counts, and source information
- [Boundary presets](boundary-presets.md) — the presets that select several boundary sets at once, such as a region or a group of countries, and the published list each one follows

Boundaries are shown as published by their providers; see the [map disclaimer](map-disclaimer.md).

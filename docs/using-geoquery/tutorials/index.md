# Tutorials

Step-by-step guides and worked examples for getting the most out of GeoQuery. For video tutorials and examples of research using GeoQuery, visit [aiddata.org/geoquery](https://www.aiddata.org/geoquery).

## Using the GeoQuery application

- [Nighttime lights for Ghana's districts](ghana-nighttime-lights.md): make a request from start to finish, then compare two years and map the change.

## For programmers

Notebooks that walk through GeoQuery's [APIs](../api.md) with Python. Each one calls the live API, so you can run it yourself. Open one on GitHub to read it, or in Google Colab to run it in your browser.

- **Public API demo**: every endpoint under `/api/public/v1/`, for datasets, boundary sets and usage figures. [Read on GitHub](https://github.com/aiddata/geoquery/blob/main/docs/using-geoquery/tutorials/public-api-demo.ipynb) · [Open in Colab](https://colab.research.google.com/github/aiddata/geoquery/blob/main/docs/using-geoquery/tutorials/public-api-demo.ipynb)
- **STAC API demo**: every endpoint under `/api/stac/v1/`, including an example with the `pystac-client` library. [Read on GitHub](https://github.com/aiddata/geoquery/blob/main/docs/using-geoquery/tutorials/stac-api-demo.ipynb) · [Open in Colab](https://colab.research.google.com/github/aiddata/geoquery/blob/main/docs/using-geoquery/tutorials/stac-api-demo.ipynb)
